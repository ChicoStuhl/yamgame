# Web Bozó 🎲

Um marcador de pontos digital para o jogo Bozó, desenvolvido em React com foco em dispositivos móveis e telas touch.

## 🎯 Sobre o Jogo

O Bozó é um jogo de dados brasileiro onde os jogadores marcam pontos em um grid específico. Este webapp facilita a marcação de pontos eliminando a necessidade de papel e caneta.

### Regras do Grid

- **Casas 1-6**: Pontuação baseada em múltiplos (ex: Casa 1 = 1, 2, 3, 4 ou 5 pontos)
- **Coluna Especial**: 
  - Casa 1: 10 ou 15 pontos
  - Casa 2: 20 ou 25 pontos  
  - Casa 3: 30 ou 35 pontos
  - Casa 4: 40 pontos ou vitória
- **Opção X**: Qualquer casa pode ser marcada com X (0 pontos)

## 🚀 Como Usar

1. **Configuração**: Escolha o número de jogadores (2-6)
2. **Nomes**: Digite o nome de cada jogador
3. **Jogo**: Clique nas casas do grid para marcar pontos
4. **Resultados**: Veja a classificação final automaticamente

## ⚡ Tecnologias

- React 18
- Vite
- CSS3 com Grid Layout
- Compatível com dispositivos touch

## 🛠️ Desenvolvimento

### Instalação
```bash
npm install
```

### Execução
```bash
npm run dev
```

### Build
```bash
npm run build
```

## 📱 Funcionalidades

- ✅ Interface responsiva
- ✅ Compatibilidade com touch screen
- ✅ Suporte para múltiplos jogadores
- ✅ Navegação automática entre turnos
- ✅ Cálculo automático de pontuação
- ✅ Tela de resultados com classificação
- ✅ Modal de pontuação temporária

## 🎮 Como Jogar

1. Selecione quantos jogadores irão participar
2. Digite os nomes dos jogadores
3. Em cada turno, clique na casa do grid que deseja marcar
4. Escolha a pontuação ou marque X para 0 pontos
5. O jogo passa automaticamente para o próximo jogador
6. Quando todos os grids estiverem completos, veja o vencedor!
